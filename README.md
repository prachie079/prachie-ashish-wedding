# Prachie & Ashish Wedding Invitation

Wedding celebrations: 24–25 January 2027, Shankar Resort, Agra.

## Deploy
Enable GitHub Pages in **Settings → Pages → Build and deployment → GitHub Actions**. The workflow deploys the repository root on pushes to main.

## RSVP
Deploy `Code.gs` as a Google Apps Script Web App (execute as you, access Anyone), then set its deployment URL in `RSVP_ENDPOINT` inside `index.html`. The script appends RSVP entries to the supplied Google Sheet.

## Media
Place the approved cover image at `assets/thumbnail.jpg` and the authorized music file at `assets/ishq-hai.mp3`. Music begins at 00:38 and Replay Invitation restarts at that point.
